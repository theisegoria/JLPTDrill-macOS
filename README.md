# JLPT Drill for macOS

JLPT Drill is a free, native macOS study app with a complete offline Japanese–English dictionary, two-way vocabulary and kanji flashcards, structured JLPT lessons, reading practice, checkpoints, and progress tracking.

## Features

- Complete offline JMdict/KANJIDIC Japanese–English dictionary
- Search by Japanese, kana, romaji, or English meaning
- Detailed word and kanji entries with readings, senses, examples, compounds, and pronunciation
- Recognition and production flashcards for vocabulary and kanji
- FSRS-6 scheduling with interval previews and configurable daily new-card limits
- 180 daily lessons spanning JLPT N5 through N1
- Six vocabulary words and two reading passages in every lesson
- Reading Lab with comprehension questions, translations, evidence, and progress history
- 30 timed kanji, vocabulary, and reading checkpoints
- Adaptive study level, catch-up lessons, weekly goals, and retention analytics
- Optional private iCloud progress sync; lessons and dictionary remain available offline
- Native light and dark appearance

## Install

1. Download the ZIP archive from the link above.
2. Unzip it.
3. Move `JLPTDrill.app` to your Applications folder.
4. Open the app and choose your starting JLPT level.

This build is currently unsigned and not notarized. If macOS blocks the first launch, Control-click `JLPTDrill.app`, choose **Open**, and confirm. The release archive contains the application bundle only; application source is not published in this repository.
