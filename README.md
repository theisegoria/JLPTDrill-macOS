# JLPT Drill for macOS

JLPT Drill is a free, native, offline-first macOS study app for Japanese vocabulary, kanji, grammar, reading, listening, flashcards, and mock-exam preparation. It prepares you for both the JLPT (N5-N1) and JFT-Basic.

## Beta status

This is a public beta, not a final reviewed release. The app performs automated curriculum, question, and speech checks, but the Japanese curriculum and generated material have not received comprehensive professional/native-speaker editorial approval. Listening quality and performance can vary by Apple-silicon Mac. Mock results and readiness are internal estimates, not official JLPT scaled scores.

The app is ad-hoc signed but not Apple-notarized. If macOS blocks the first launch, Control-click `JLPTDrill.app`, choose **Open**, and confirm.

## Install

1. Download the ZIP archive from the link above.
2. Unzip it.
3. Move `JLPTDrill.app` to your Applications folder.
4. Control-click the app, choose **Open**, and confirm if prompted.
5. Choose your target level and study-plan settings.

The release archive contains the application bundle only; application source is not published in this repository.
