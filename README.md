# JLPT Drill for macOS

JLPT Drill is a free, native, offline-first macOS study app for Japanese vocabulary, kanji, grammar, reading, listening, flashcards, and mock-exam preparation.

## What's in v4

- Today, Learn, Practice, and Progress destinations
- Complete offline JMdict/KANJIDIC Japanese-English dictionary
- Search by Japanese, kana, romaji, or English meaning
- Detailed word and kanji entries with readings, senses, examples, compounds, and pronunciation
- Recognition and production flashcards for vocabulary and kanji
- FSRS-6 scheduling with interval previews and configurable daily new-card limits
- Unofficial competency-based N5-N1 curriculum with vocabulary, kanji, and grammar coverage
- Grammar Drill, expanded Reading Lab, and a unified Mistake Notebook
- Offline Listening Lab with locally generated Qwen speech and stable anonymous voices
- Practice and strict mock exams with reproducible procedural questions
- Adaptive daily plans, mastery evidence, pacing, readiness estimates, and progress analytics
- Optional private iCloud progress sync; curriculum, dictionary, and speech model remain local
- Native light and dark appearance

## Beta status

This is a public v4 beta, not a final reviewed release. The app performs automated curriculum, question, and speech checks, but the Japanese curriculum and generated material have not received comprehensive professional/native-speaker editorial approval. Listening quality and performance can vary by Apple-silicon Mac. Mock results and readiness are internal estimates, not official JLPT scaled scores.

The app is ad-hoc signed but not Apple-notarized. If macOS blocks the first launch, Control-click `JLPTDrill.app`, choose **Open**, and confirm.

## Install

1. Download the ZIP archive from the link above.
2. Unzip it.
3. Move `JLPTDrill.app` to your Applications folder.
4. Control-click the app, choose **Open**, and confirm if prompted.
5. Choose your target level and study-plan settings.

The release archive contains the application bundle only; application source is not published in this repository.
